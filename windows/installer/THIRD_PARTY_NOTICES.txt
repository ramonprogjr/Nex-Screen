3. .NET runtime and libraries
-----------------------------
NexScreen.Companion.exe is a self-contained .NET 8 application. It embeds the .NET runtime
(https://github.com/dotnet/runtime, MIT, (c) .NET Foundation and Contributors) and Vortice.Windows
(https://github.com/amerkoleci/Vortice.Windows, MIT, (c) Amer Koleci and contributors).


4. Windows-driver-samples (nexscreen-vdd-ctl.exe)
-------------------------------------------------
nexscreen-vdd-ctl.exe, which installs and removes the virtual display device, is derived from the IddSampleApp of
https://github.com/microsoft/Windows-driver-samples (video/IndirectDisplay) under the Microsoft Public License
(MS-PL). The license text and the list of changes are in driver-THIRD_PARTY.md in this folder.
